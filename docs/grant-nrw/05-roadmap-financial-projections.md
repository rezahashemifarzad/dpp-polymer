# 5. Roadmap & Financial Projections

> **All figures in this section are illustrative placeholders**, sized to a plausible trajectory for an NRW-based B2B compliance SaaS serving the polymer/chemical Mittelstand. They are provided as a structural template — the shape and logic of the model — not as validated numbers. Before this section is used in a binding grant application, the founding team must replace every figure with its own bottom-up model built from actual pilot pricing, real customer conversations, and actual cost quotes (cloud hosting, headcount, compliance/legal support).

## 5.1 Commercialization roadmap

### Phase 0 — Foundation (complete)
Core platform built and live: passport data model, cryptographic audit ledger, GS1 QR/Digital Link engine, certification verification workflow, auditor and buyer portals, ESG/compliance analytics suite, supplier onboarding, multi-language public passport page. This phase is the basis for the technical claims in Section 4 and is already delivered, not projected.

### Phase 1 — Pilot validation (Months 1–6)
- Onboard 3–5 pilot manufacturer customers in the NRW chemical/plastics corridor, ideally spanning at least one compounder, one mechanical/chemical recycler, and one converter, to validate the data model against real production data diversity.
- Onboard a small initial auditor network (2–4 independent auditors or one auditing firm) to exercise the verification workflow under real conditions, not just internal testing.
- Establish the RWTH Aachen / CCE (or equivalent) advisory relationship referenced in Section 3.3, converting it from an aspiration into a named, citable partnership.
- Harden production-grade session authentication and complete a first external security review, closing the gaps flagged at the end of Section 4.8, ahead of wider commercial rollout.
- File the first NRW.BANK / EFRE.NRW / Ressource.NRW grant application(s) using this document package, informed by real pilot traction data rather than projections alone.

### Phase 2 — Regional scale-up (Months 7–18)
- Convert pilot customers to paying subscriptions; expand direct sales across the broader NRW chemical/plastics Mittelstand base.
- Ship the Buyer API/CSRD-integration tier commercially, targeting at least one anchor OEM or converter buyer relationship as a reference case.
- Build out the first-class batch-weight field and complete mass-based ESG metric coverage (flagged as planned work in Section 4.8).
- Formalize the auditor network into a structured, trained, and possibly certified verification-partner program.
- Begin tracking toward and reporting against whichever NRW/EU grant milestones were committed to in Phase 1's application(s).

### Phase 3 — DACH/EU expansion (Months 19–36)
- Expand direct sales into the wider DACH chemical cluster (leveraging NRW case studies and reference customers as the primary sales asset).
- Evaluate the white-label/multi-tenant licensing model (Section 2.2, item 6) for industry associations or certification bodies as a second growth vector.
- Pursue a follow-on research/translation grant (e.g. a Fraunhofer-affiliated applied-research call) building on the platform's accumulated verified batch-record dataset, per the Year 2+ opportunity flagged in Section 3.3.
- Reassess entry into adjacent EU markets (Benelux, broader DACH) as ESPR's delegated acts for plastics/packaging product groups come into force and create the same compliance urgency there that NRW's chemical cluster faces today.

**Modeling notes for the team, to replace before submission:**

1. Anchor the subscription tiers to actual pilot pricing conversations rather than a top-down guess — B2B SaaS pricing for a compliance-critical, low-churn-tolerance product like this is usually set by what a customer's *cost of non-compliance* (fines, lost OEM contracts, manual compliance labor) is worth avoiding, not by a generic per-seat SaaS benchmark.
2. Build the cost-structure line items (Section 2.3) into an actual monthly burn model before stating any runway or grant-need figure in a real application — NRW.BANK/EFRE.NRW applications typically require a documented use-of-funds breakdown, not just a headline ask.
3. State any specific funding ask amount only after checking the current ceiling and co-financing rate of the specific program being applied to (Section 3.2) — do not carry a number from this template into a real application without that check, since ceilings and rates vary by program and change between funding periods.
4. Where the grant program requires job-creation or regional-economic-impact projections (common for EFRE.NRW/structural-funds-adjacent programs), derive those directly from the headcount line above rather than stating a separate, disconnected impact number.
